 Hue4U
An accessibility-focused website for people with color vision deficiencies (color blindness).  

What is Hue4U?

Hue4U is a web application designed to assist individuals with color blindness by helping them identify and differentiate colors in real-time. Whether you're uploading an image or taking a live photo, Hue4U analyzes the colors and displays the names for better understanding.

We believe accessibility is a right, not a feature — and Hue4U was built with that in mind.


 Key Features

- Image Upload or Live Capture– Upload an image or use your camera to take one.
- Color Detection – Instantly get the color name by clicking anywhere on the image.
- Vision Type Themes – Adaptive UI themes for Protanopia, Deuteranopia, Tritanopia, and Achromatopsia.
- User Authentication – Sign up, log in, and keep a history of images using Firebase Auth.
- Data Storage– Stores image info and history using Firebase Realtime Database.
- Modern UI – Designed with Tailwind CSS for a clean, responsive look.
- Optional Accessibility Features – Planned: Text-to-speech support and keyboard navigation.

---

 Tech Stack

- Frontend: HTML, CSS, JavaScript, Tailwind CSS
- Computer Vision: OpenCV.js
- Backend & Auth: Firebase Authentication
- Database: Firebase Realtime Database
- Deployment: GitHub Pages (or other)
